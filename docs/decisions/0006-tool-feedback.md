# 工具反馈与恢复指引

日期：2026-11-16。状态：已实现。

## 问题

实测子代理写入正确被拒绝，但 STASH_UNSUPPORTED 的固定模板要求改用工作区或当前会话路径。它混淆了代理权限、目标只读和操作不支持，可能让模型不断换路径重试。此前测试只断言错误码，未验证模型收到的原因和补救方式。

检查还发现读取预算错误附加缩短规则的建议、失效游标提示写前重读、重复 create 只提示重新读取，以及删除会话笔记仍附加索引和提升说明。跨会话目录中的裸 /notes/ 路径容易指向工作区同名笔记。

## 决策

保留现有权限、存储格式和写入规则，新增 STASH_READ_ONLY 和 STASH_ALREADY_EXISTS；前者通过原因区分子代理、其他会话和历史。其余错误扩展已有结构化 detail，并由 core/templates 渲染完整说明。具体原因替代通用文案，避免两种相互矛盾的操作建议同时出现；不根据中文异常字符串做匹配，也不透传底层异常正文。

子代理常驻上下文明确工作区和会话层均只读，错误建议将拟议修改交给父代理考虑，不引导模型自行修改权限。规则删除与归档在读取资格检查前拒绝，避免要求先读完再执行一个始终不支持的操作。重复创建在存储原子校验处分类，保留并发保护。

归档与删除使用对应回执，归档不会解除已存在的规则引用。会话笔记提示只说明作用域、显式检索与提升方式，不承诺立即被索引。跨会话目录返回完整引用；搜索注明笔记来自当前存储状态，不把会话时间筛选描述成历史笔记版本查询。

## 验证

真实宿主工具测试检查完整错误原因、失败后文件/提交/修改日志不变，以及按照提示修正后的操作成功。覆盖子代理开关与两层记忆、其他会话和历史只读、规则清空、重复创建、归档/删除回执、查询选项、时间、分页、预算、跨会话引用和异常正文不回显。标准与 PTC SDK 验收检查新错误进入后续模型请求，并验证失败没有覆盖原笔记。测试仅连接本地 mock，不代表真实模型行为评估。
