# 0003：DSH 0.2.2-rc.3 宿主基线

日期：2026-11-15。状态：已实施，stash 保持 0.2.1。

开发基线由 npm 0.2.2-rc.1 升级至 0.2.2-rc.3，参照上游标签 dsh-v0.2.2-rc.3（38a6a5c965aa99ab525161efb7cc5cf1fe62fced）。运行依赖、peer 依赖、SDK、Typert 生成器与测试工具同步锁定，避免宿主包混用两个预发布版本。安装通过仓库默认的 npmmirror 完成。

engines.dsh 与 doctor 的支持范围统一为 >=0.2.2-rc.3 <0.3.0-0。开发阶段以新基线验证，不保留对 rc.1、rc.2 的支持声明；上限继续排除 0.3.0 预发布版。历史决策和原始规划保留当时的宿主版本。

对比 rc.1 至 rc.3 源码后，stash 使用的 agent/pre-step、会话 surface、消息来源、工具结果 meta、压缩 checkpoint、作用域提示与工具、Remote 及客户端工厂契约保持可用。上游将子代理运行时归属移出 AgentRegistry，stash 仍按持久化会话 header.origin 判定子代理只读，无需改动该适配逻辑。领域契约、持久格式和模型模板保持不变。

Windows 本地 pnpm check 通过，覆盖格式、lint、构建、严格类型、29 项单元/宿主/客户端测试及 4 项真实进程端到端测试。端到端验证 SDK 写入、外部交错、跨会话与工作区隔离、压缩与重启恢复、离线重放、tarball 安装和 Web Gateway；Gateway 返回的宿主版本须与实际安装的 CLI 一致。测试使用临时 DSH_HOME 和本地 mock。Linux/macOS 由既有 CI 矩阵验证，本次未在本地运行。
