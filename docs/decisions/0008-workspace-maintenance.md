# 工作区整理计划与回滚

日期：2026-11-18。状态：已实现。

- **模型提出，用户执行。** 普通会话仍是两个记忆工具。专用 DSH 会话只开放工作区读取与 `stash_plan`，移除全局工具并以执行守卫约束其他作用域的能力。原会话的可发现性设置传给新会话。用独立 Remote 确认内容哈希和有效规则行，而不用对话里的一句“同意”授权写入；这也覆盖修改被规则导入的笔记。
- **读全而不是请求百次。** 整理会话的目录视图提供按预算分页的完整语料；宿主验证当前 agent 已读到结尾，且快照仍与草稿一致。普通工具的目录语义不变。批量阅读不会让全部笔记突然变成“最近使用”。计划只涉及工作区；从会话提升笔记继续使用现有的显式提升入口，不扫描所有会话。
- **日志是唯一的跳转真相。** 不另写 `.redirects.json`：若文件已删除但映射未写成功，就会使旧引用失效。重定向和文件变更同在恢复记录中；支持多次合并/移动的链，整体清空释放对应旧路径。历史及统计不是回滚目标。若一条路径后来又被操作（即使内容相同），优先拒绝回滚，不尝试变基其他整理组。
- **保守的健康信号。** 用 Git HEAD 前缀比较已记录的 `verified` 提交，不把它解释为代码语义过期。不在 Git 工作区、Git 不可用或字段无法解析时标为不可比较。统计不决定整理时机，插件没有定时任务。
- **兼容边界。** 保持既有日志 v1；整理行使用新的可选字段，旧插件的严格解码会拒绝而不是忽略。清除遗留锁之前须确认持锁进程已停止；不宣称能与任意不遵守锁的外部编辑器进行跨文件原子事务。
